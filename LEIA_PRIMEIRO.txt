AL CAPONE | AGENDAMENTO GRATUITO COM SUPABASE

O endereço e a chave pública já estão configurados no app.js e minha.js.
Não há servidor Python, Docker nem Render neste projeto.

1. No Supabase, acesse o SQL Editor e execute o arquivo 01_ATIVAR_NO_SUPABASE.sql.
2. Execute também o arquivo 02_PAINEL_ADMIN.sql para habilitar o painel administrativo.
3. Para ativar os cupons, execute o arquivo 03_CUPONS_DESCONTO.sql UMA VEZ, depois dos arquivos 01 e 02.
4. Publique esta pasta como site estático no GitHub Pages, em um repositório SEPARADO da landing atual.
5. Abra o endereço do GitHub Pages e teste um agendamento. Ele será salvo no banco Supabase.

IMPORTANTE: a landing atual não foi modificada. Este projeto contém apenas
as telas de agendamento e consulta/cancelamento do cliente. Painel de barbeiros
será integrado posteriormente.

Apenas a publishable key foi incorporada. Nenhuma senha nem secret key.
A publishable key pode ficar no front-end; todas as tabelas estão bloqueadas para leitura pública.

Projeto Supabase: https://supabase.com/dashboard/project/vsqvzfwlndkwmajkvtuc

Fotos, logo e visual seguem a versão criada anteriormente.

AVISO: o banco e a interface foram preparados e validados estaticamente, mas
não foram testados contra o seu projeto Supabase (não tenho acesso autenticado).
A oferta gratuita do Supabase tem limites e pode pausar o projeto por inatividade.


ATUALIZAÇÃO VISUAL E CONFIRMAÇÃO:
- Nomes dos profissionais padronizados na paleta terrosa.
- Setas do calendário redesenhadas.
- Após confirmar, o cliente pode abrir o Google Agenda, baixar um arquivo .ics com dois alertas (1 hora e 30 minutos antes, se o app aceitar) e abrir o WhatsApp com o resumo pronto para enviar ao próprio número.
- O envio do WhatsApp exige que o cliente toque em ENVIAR.
- O link do Google Agenda cria o evento; as notificações do Google dependem das preferências da conta.

ATUALIZAÇÃO — CAMPANHAS E CUPONS DE DESCONTO:
- O painel administrativo ganhou a seção CAMPANHAS E CUPONS.
- É possível criar/editar campanhas com código, desconto percentual ou fixo, período, quantidade total de usos e limite por cliente.
- As campanhas podem ser pausadas e reativadas.
- O cliente informa o código na etapa final do agendamento, depois de preencher o WhatsApp.
- O banco valida novamente o cupom no momento da reserva e registra o desconto aplicado.
- Antes de publicar os arquivos atualizados, execute 03_CUPONS_DESCONTO.sql no SQL Editor do Supabase.


ATUALIZAÇÃO — CLIENTES VIP E FIDELIDADE:
- Execute 04_CLIENTE_VIP.sql UMA VEZ, depois dos scripts 01, 02 e 03.
- O painel ganhou cadastro individual de clientes VIP, código vinculado ao WhatsApp, descontos, horários exclusivos por profissional/data, promoções, combos informativos, regras de pontuação, recompensas e gestão de resgates. O agendamento atual continua selecionando um serviço por reserva; combos são exibidos na área VIP como ofertas e condições.
- O cliente valida o código VIP e o WhatsApp na página pública, antes de escolher data e horário.
- A pontuação é creditada somente quando a reserva VIP é marcada como CONCLUÍDO. Padrão inicial: 1 ponto por R$ 1,00 pago; a taxa pode ser alterada no painel.
- Os pontos de uma recompensa ficam reservados quando o cliente solicita o resgate e só são debitados quando a equipe marca como ENTREGUE.
- Cupons e benefícios VIP não são acumulados; o sistema aplica um benefício por reserva.
- Para agendamentos manuais de clientes VIP, informe o código VIP no formulário do painel para registrar o vínculo e liberar horários exclusivos.
